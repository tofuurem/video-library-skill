# video-library

Скилл для [Claude Code](https://claude.com/claude-code): наводит порядок в отснятом видео на внешних дисках и помнит, что снято в каждом клипе. macOS и Linux: модели для карты видео выбираются под машину (на Маке — Apple Vision и MLX, на Linux — открытые модели, с NVIDIA — на GPU), см. [engines.md в reel-studio](https://github.com/tofuurem/reel-studio-skill/blob/main/references/engines.md).

## Установка

Вставь в Claude Code:

```text
Установи скилл video-library: склонируй https://github.com/tofuurem/video-library-skill в ~/.claude/skills/video-library и запусти python3 -I ~/.claude/skills/video-library/scripts/deps.py --install. Спроси меня, нужна ли карта видео (поставит скилл reel-studio и его окружения, несколько ГБ) и описания сцен (ещё ≈ 5,4 ГБ на Apple Silicon; на Intel Mac и Linux ≈ 9 ГБ, с NVIDIA ≈ 17 ГБ); если да — добавь --with map и/или --with descriptions. Доведи до DEPS_OK. То, что требует пароля, дай мне выполнить самому.
```

Или вручную:

```bash
git clone https://github.com/tofuurem/video-library-skill ~/.claude/skills/video-library
python3 -I ~/.claude/skills/video-library/scripts/deps.py --install
```

`deps.py` без флагов только показывает, что есть на этом компьютере, какой движок выбран для каждой задачи и что из скилла здесь заработает. На Linux нет CapCut (черновики правятся, только если их папка доступна) и двойного клика по «Разложить.command» — раскладка запускается командой; Windows — через WSL2.

## Что получится

Скажи Claude Code: «подключил диск, наведи порядок», «разложи inbox», «что где снято», «найди, где я говорю про билеты», «какие ролики можно сделать», «что можно удалить», «архивируем». На каждом диске будет:

- **`Source Video/год/месяц/день место/Камера_Профиль/`** — клипы по съёмочным дням; одна папка камеры = один LUT, профиль (D-Log, HLG…) читается из файла. Имена файлов не меняются, всё только переименованиями внутри диска, с журналом и откатом. Новое с карты — в `_inbox` и двойной клик по «Разложить.command».
- **`Video Production/` и `Video Archive/`** — ролики в работе и готовые (`final/`, `project/`, список использованных клипов).
- **`ВСЕ ДИСКИ.md`** — каталог всех дисков: что где снято, какие клипы в каких роликах (включая черновики CapCut), что можно освободить. Дубликаты проверяются побайтово, удаление — только после твоего «да».
- **`_карта/<день>/день.md`** (с `--with map`) — что в каждом клипе: речь, сцены, лучшие кадры, оценки ★ брать / ◐ запас / ○ можно удалить. Поиск по словам сразу по всем дискам, даже отключённым.
- **`_docs/ИДЕИ РОЛИКОВ.md`** (по карте) — что можно сделать из отснятого: куски речи с таймкодами, короткие рилсы с оценкой, рубрики, подборки планов, что доснять и что размыть. Выбранные идеи монтирует reel-studio.

Монтаж роликов — в соседнем скилле [reel-studio](https://github.com/tofuurem/reel-studio-skill). Полная инструкция — в [SKILL.md](SKILL.md).
