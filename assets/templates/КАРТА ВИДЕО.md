# Карта видео — что снято в каждом клипе

Файл поставлен на {{DISK}} скиллом video-library ({{DATE}}). Общие разделы одинаковые на всех дисках библиотеки; «Особенности {{DISK}}» и «Состояние» — только про этот диск, их дописывает Claude.
Опись диска целиком (что лежит в корне, исходники по местам и камерам, где использованы) — `_docs/ИНВЕНТАРИЗАЦИЯ.md`, когда она сделана. Идеи роликов по карте — `_docs/ИДЕИ РОЛИКОВ.md`.

Зачем: находить материал под ролик, решать, что удалить, и помнить, что снято, даже если исходники удалены.

## Где лежит
- `Source Video/_карта/<папка дня>/клипы.json` — всё о каждом клипе: речь с таймкодами, звуки, сцены, лучшие кадры, метки Vision, текст в кадре, описания отрезков. Сюда же Claude пишет пометки: описание, теги, оценку и моменты.
- `Source Video/_карта/<папка дня>/листы/<клип>.jpg` — до 16 лучших кадров клипа с таймкодами, с LUT.
- `Source Video/_карта/<папка дня>/день.md` — описание дня: итог, хронология с оценками, лучшие моменты, что уже использовано, что удалено, что можно удалить. Пишет Claude.
- `Source Video/_карта/поиск.sqlite` — поиск по всем дням диска сразу.
- Рабочие кадры и звук хранятся на Mac, `~/.cache/video-map/work/<день>`. Их можно удалить: карта от них не зависит (но пересборка дня тогда сделает все этапы заново).
- Фото (`*_Photo`) в карту не входят: они есть в `Source Video/_catalog.csv`.

## Как устроено
Каждый слой смотрит только то, что отобрал предыдущий.

| Слой | Чем | Почему так |
|---|---|---|
| Кадры | ключевые кадры камеры, 384 px, с LUT профиля, один проход по файлу | полное декодирование в разы медленнее; LOG без LUT модели видят хуже |
| Сцены | «отпечатки» кадров (на Mac — Apple Vision, на Linux — DINOv2): новая сцена, когда картинка заметно ушла от прежней | в сырых дублях нет склеек, детекторы склеек тут не помогают |
| Лучший кадр | в каждой сцене самый резкий и нормально экспонированный | не «кадр раз в секунду», который может быть смазан |
| Метки | метки, текст в кадре (ru/en), люди, лица (Apple Vision или открытые модели) | быстро и бесплатно; метки грубые — для фильтров, не для сюжета |
| Речь | Silero VAD → GigaAM v3, только на речи | сильная открытая модель для русского; без VAD модели сочиняют текст на ветре и моторе |
| Звуки | Apple SoundAnalysis или AST (AudioSet), окна 3 с | видно, где ветер в микрофоне, мотор, море |
| Описание | Qwen3-VL (на Mac 8B 4 бит через MLX, на Linux через transformers или llama.cpp, локально) по лучшим кадрам отрезка ≤ 150 с и его расшифровке | бесплатно, ничего не уходит с компьютера, по-русски; ошибается в мелочах |
| День | Claude по `клипы.json`, расшифровке и листам | сюжет, оценки, моменты — то, что машина сама не решит |

## Сторож памяти
Движки выбираются под компьютер (таблица: `engines.py` из reel-studio). Карту одного диска строить одними движками: сцены и метки разных движков не сравнимы. Тяжёлые модели запускаются только через сторожа `Source Video/_tools/mem_guard.py`, иначе компьютер может зависнуть. Потолок для Qwen — 11 ГБ на MLX и llama.cpp, 14 ГБ на transformers; для речи — 4 ГБ; компьютеру всегда остаётся не меньше 4 ГБ свободной памяти. Если сторож остановил этап (код 137), обычно память занята другой программой: подожди и запусти этап заново — готовое пропускается, работа продолжается с места остановки. Лимиты не снижать. На Mac с памятью меньше 16 ГБ этап описаний (`vlm`) пропускать.

## Команды (из `Source Video/_tools`)

| Что | Команда |
|---|---|
| Карта дней | `python3 -I video_map.py 2026-07-14 2026-07-15` |
| Отдельные этапы | `… --only extract,frames,speech,sounds,vlm,assemble` |
| Пересобрать только поиск | `python3 -I video_map.py --index` |
| Сводка дня для чтения | `python3 -I vm_brief.py 2026-07-14 [--speech 0] [--clip 0012]` |
| Поиск (сразу по всем дискам; неподключённые — по копии на Mac `~/.cache/video-map/поиск/`) | `python3 -I vm_search.py "трамва* OR закат*" [--kind речь] [--day 2026-07-14] [--disk {{DISK}}] [--path]` |
| Пометки Claude | `python3 -I vm_annotate.py 2026-07-14 пометки.json` |

Поиск: слова через пробел ищутся вместе, `OR` — любое из, `*` — любое окончание (`трамва*` найдёт «трамвай» и «трамваем»).
Скорость: примерно 10–15 минут работы Mac на час видео; больше всего времени уходит на чтение диска и описания Qwen. Остановленный прогон продолжается с места остановки.

## Оценки
- **★ брать** — сюжет, лучшие кадры.
- **◐ запас** — перебивки, может пригодиться.
- **○ можно удалить** — брак, пустой кадр, повтор дубля.

«○» — только подсказка. Удалять — по отдельному «да» и после сверки с проектами (`ВСЕ ДИСКИ — каталог.csv`, колонка «использован в»). Клипы, которые нужны для идеи из `_docs/ИДЕИ РОЛИКОВ.md` (например, срывы и дубли для рубрики), не удалять, даже если они «○».
